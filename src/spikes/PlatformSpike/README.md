# PlatformSpike — 技術検証スパイク

SPEC §13.1 の「要検証」項目を潰すための使い捨てプロジェクト。製品コードには流用せず、結果だけを SPEC に反映して削除する。

## 実行

前提: .NET 10 SDK（無ければ csproj の `TargetFramework` を `net8.0` に変更）

```
cd src/spikes/PlatformSpike
dotnet restore
dotnet run
```

初回は NuGet から Avalonia / SharpHook を取得する。復元に失敗したら csproj のバージョン指定（`11.3.*` / `5.3.*`）を `dotnet package search Avalonia` 等で見つかる最新安定版に合わせる。

### macOS の注意

- `dotnet run` で起動した場合、権限は **ターミナル（または dotnet ホスト）** に対して求められる。システム設定 → プライバシーとセキュリティ → 「入力監視」「アクセシビリティ」でターミナルを許可し、アプリを再起動する。
- どちらの権限で `hook enabled` になったかを記録する（§13.1-3 の答え）。`HOOK FAILED: <UioHookResult>` の値も記録。
- Dock 非表示 (LSUIElement) は `.app` バンドルの Info.plist が必要なため、このスパイクでは **未検証**。製品の初回ビルド時に確認する。
- フォーカス返却（F）は Mac では未実装。表示前にアクティブだったアプリへ戻るかを目視で記録するだけでよい。

## 操作とチェックリスト

起動すると「control panel」ウィンドウが出てログを流し始める。以下を順に試し、結果を `RESULTS.md`（このフォルダに新規作成）に OS ごとに記録する。

1. **A** 起動直後のログに `hook enabled` が出る。
   - Mac: 権限ダイアログ → 許可 → 再起動 で出るか。どの権限が必要だったか。
2. **B** 別アプリ（メモ帳 / TextEdit）にフォーカスを置いて `Ctrl+Alt+Space`。
   - ポップアップが出る／ログに `HOTKEY` が出る／メモ帳にスペースが **入力されない**（抑止 ON）。
   - 「ホットキーを抑止」を OFF にして再試行 → スペースが入力される。
   - もう一度押すとトグルで閉じる。
3. **C** 同じく別アプリ上で
   - `Ctrl+中クリック`（既定トリガー）→ 出る。下のアプリに届かない（ブラウザのリンク上で新規タブが開かない）。修飾キーなしの中クリックは通常どおり。
   - `Alt+中クリック` → 出る。下のアプリに中クリックが届かない（ブラウザのリンク上で試す）。
   - 中ボタンを 400ms 以上押す → 出る。**押下時点の中クリックは下のアプリに届いてしまう**はず。許容できるか判断。
   - 中ボタン短押し → 出ない。
   - 左右ボタン同時 → 出る。片方ずつ普通にクリック → 出ない。
4. **D** ポップアップが出た状態で
   - タイトルバー無し・角丸・半透明になっているか（`transparency=` ログも確認）。
   - タスクバー / Dock にアイコンが出ないか。
   - 「常に最前面」ON/OFF で重ね順が変わるか。
5. **E** 画面の右下隅近くでトリガー → 盤面が画面内に収まるか。
   - マルチモニタ・スケーリング 125%/150% の環境なら、カーソル位置と表示位置がズレないか。`TRIGGER ... (x,y)` と `popup opened at` のログを比較。
6. **F** ポップアップ表示後、盤面外をクリック → 閉じる（`popup deactivated`）。
   - Win: `restore foreground → ok` が出て、直前のアプリに入力フォーカスが戻るか。
   - Item ボタンをクリック → 閉じて、直前のアプリにフォーカスが戻るか。
7. **G** Explorer / Finder から「ここにドロップ」へ
   - ファイル 1 件 / 複数件 / フォルダ / (Win) .lnk / (Mac) .app を順にドロップ → ログの `DROP` 行にフルパスが出るか。.lnk はリンク先ではなく .lnk 自体のパスになるはず（解決は製品側で実装）。
   - ブラウザのアドレスバーやリンクをドロップ → `text:` または `file:` としてどう届くか。
8. **H** `show latency ≈ N ms` を 5 回ほど記録。目標 100ms 以内。
9. **I** (Win) デスクトップの壁紙上で `Alt+中クリック` → `window under cursor: Progman` または `WorkerW`。他アプリ上では別のクラス名。
